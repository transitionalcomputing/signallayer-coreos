## Implementation

See [source model and limits](../../management-lifecycle/MODEL.md).
The library has no dependencies, unsafe code, I/O or CLI. It does not join the
Cargo workspace or add binaries. Existing P3-1b identity source is not called.
It binds transaction/invocation/content/object identities, exact persistence
receipts, one-use guard and verifier activation, successful oneshot completion,
durable publication/inhibit release and latched failure. Every retry returns to state 1 with a fresh transaction; only actual coordinator
restart requires a new reset ID. Same-live-reset retries are explicitly modeled. No live backend exists.
