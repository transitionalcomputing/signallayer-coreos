--offline-output <new-absolute-bundle>` accepts a file location only. Trusted

It does not compile, download, execute the ELF or accept boot/runtime arguments.

The source oracle is compiled before supplied bytes are read or a tree is
materialized. It binds the original recipe inputs plus fixed F5 lock/contract
hashes. Input capture rejects nonregular objects, aliases, symlinks, unsafe
modes/ownership, unreviewed xattrs/ACL/capability, excessive size, and observed
inode/mount/path/content races. Offline ancestor revalidation is not an installed
path or hostile-root-writer guarantee.

The captured bytes must match the reviewed size/digest. The captured source of
`verify-static-fixture` must match its unchanged F5 contract hash. Isolated Python
runs that checker on a private copy with the reviewed expected digest; supplied
ELF code is never executed. The same verified bytes reach materialization, not a
second read of the supplied path. The unchanged independent rootfs verifier must
accept source-pinned staging before rename/PASS. Failure leaves no accepted new
bundle; previous outputs are never overwritten.

These source-held records depend on a reviewed checkout and build contract;
they are not signatures or self-authenticating owner approval. A writer able to
replace all review records can change their authority. No broader trust claim
was introduced.

### Equivalent acceptance bypass and measured sensitivity

The isolated mutation makes these three semantic edits to `build_bundle()`:

1. After `pin = reviewed_artifact(source)`, replace `pin['sha256']` with the
   supplied file's digest.
2. Replace `pin['size']` with the supplied file's size.
3. Remove only `reviewed_artifact(source) != pin` from the final revalidation;
   retain `source_snapshot(SOURCE_ROOT) != source`.

The static ELF checker and independent staged verifier remain mandatory, but
the mutant supplies them caller-derived expectations. A separate witness
actually publishes the wrong same-size ELF through this mutant; the unchanged
original trusted manifest rejects that bundle. This is a regression-sensitivity
counterexample in disposable source copies, **not** a bypass of unchanged
production source. The equivalent mutation is permitted by the lead comment;
it is not represented as the unavailable exact Claude three-line patch.
