## Implemented

- `config/coreos-source-inventory.json` preserves all prior measured inventory
  values and `accepted_source`, adding actual existing Cargo binary targets and
  tmpfiles declarations. Its separate `planned_inventory` records approved
  proposed names/paths, packages, masks and future source roots, explicitly
  `planned-not-installed`.
- `tools/coreos-inventory` and the exact build contract pin the canonical plan
  and missing/present state of reserved inputs. New files/directories, changed
  bytes/owner-executable state, special permission bits, symlink inputs and
  altered/removed plans fail. Existing complete
  instruction and COPY-provenance comparison still rejects unauthorized build
  commands, source helpers and installed paths. Candidate generation retains the
  plan but marks the candidate unapproved.
- The 543-NEVRA complete **pinned-base** lock, 169-package Requires closure and
  exact inherited unit/config/binfmt inventory are preserved as measurements.
  The local RPM companion had contained a duplicate proposal; the exact
  preserved original was restored, matching its recorded SHA-256
  `8c1fdfa9d787355b1dcca8ec65dc838856290ee09f5c0a6afa7bba0afcb249b4`.
- One preflight-only Containerfile COPY makes these three inputs available to
  the checker inside OCI. A file-copy fixture reproduces that context and runs
  the real checker; no RUN instruction or image build is executed by the test.
- Runtime directive assertions are deferred to the R1/R2-corrected P3-1d
  specification. The superseded directive list is not encoded. B's security
  acceptance is reserved; no upstream engine-risk waiver is inferred.
