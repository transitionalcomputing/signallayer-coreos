and future programs are **UNPROVEN**. These limitations are not waived by the

## PR #46 C1/C2 remediation

The original two-part native evidence above is preserved as history. It does
not establish the corrected revision's end-to-end result. C1 now pins the
independently reviewed digest above and size **15,725,600** in the source-gated
lock. Each compilation must match both before `verify_elf` receives that reviewed
digest; the two-output equality guard remains. A new digest or size is a review
decision, never a value learned automatically from a rebuild.

C2 exercises actual preparation/controller sequencing with deterministic mocked
external boundaries, including pre-install refusal, exact transaction arguments,
post-install equality, measured tool versions, rootless/image/provenance gates,
ELF invocation, archive safety, fixed isolation and smoke failures. The independent
inventory arithmetic reads the separate 543-record base evidence and proves
`543 - 4 + 23 + 1 = 563`. Mutation replay in disposable source copies must show
actual test assertion failures; syntax/import errors are not passing controls.
These are offline regression tests, not additional native or installed proof.

R3 explicitly selects OCI build isolation, anchors the fingerprint to the
successful RPM signature line, rejects malformed preparation provenance and
validates all archive members before materializing outputs. Owned containers
are removed; prepared builder images are deliberately retained for review and
evidence, with no general image-pruning operation. R1 lock relocation is deferred
to avoid unrelated path/source-gate churn; this is not a new acceptance gate.
