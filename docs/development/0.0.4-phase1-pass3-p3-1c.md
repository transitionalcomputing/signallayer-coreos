## Implemented

- `tools/build-management-rootfs`: fixed reviewed recipe/input selection; exact
  input SHA checks; rejects unlisted source files/empty directories, aliases,
  symlinks, unsupported objects, special modes and non-SELinux xattrs. Expected
  manifest is compiled from source before materialization, not learned from
  Podman or a mutable result. Root-owned output modes and timestamps normalize
  independently of checkout umask. Private staging and atomic publication
  refuse an existing bundle and leave no accepted output on injected pre-publish
  interruption.
- `tools/verify-management-rootfs`: independent parser/scanner, no builder
  imports. Requires separately pinned manifest SHA, canonical/versioned JSON,
  exact tree, root UID/GID, mode, bytes, symlink target, hardlink equivalence
  (including external aliases), bounded sizes/counts and non-SELinux xattrs.
  FD-relative `O_NOFOLLOW`, mount IDs, identity rechecks and two measurements
  reject observed path/mount/content substitution. No runtime path-selection
  API or launch authority is installed.
- `management-fixture`: a pinned harmless data skeleton, `/etc/mtab`,
  `/run/.containerenv`, `/var` and other future mount targets, plus an uncompiled
  harmless Rust source. No binary, Cargo workspace member, static library or
  machine-local management identity is included. Hardlink equivalence has an
  actual positive group and split/extra-alias negatives.
- `Containerfile`: exactly two additional COPY instructions in
  **release-preflight** expose the reserved source inputs to inventory checks.
  All subsequent build stages and the final runtime stage are byte-equivalent
  in their parsed instructions. No build or final-stage packaging was run.
- `config/coreos-build-contract.json`: adopted the separately emitted candidate
  after comparing exact differences: these two COPYs/provenance, changed
  Containerfile hash, new tool/fixture hashes and present planned source roots.
  Accepted `config/coreos-source-inventory.json` remains **byte-identical**;
  planned glibc-static and all 543 base NEVRAs remain untouched. `recorded_from`
  continues to identify the prior reviewed history; it is not fresh artifact
  provenance or self-authorization.

The fixture does not yet satisfy a **runnable production rootfs** deliverable.
That limitation is deliberate: binary/toolchain and exact SELinux label proof
must not be inferred from a passing source suite.
