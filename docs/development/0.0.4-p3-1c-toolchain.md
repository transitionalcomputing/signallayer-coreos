## Source/review evidence and decision

The existing planned build-only package is recorded in
`config/coreos-source-inventory.json`; the F5 mismatch is documented in
`docs/development/0.0.4-pr40-review-corrections.md`. Exact dependency requirements
of a compatible static RPM cannot be measured here because that RPM and cached
repository metadata are unavailable. No networked repository query or package transaction was attempted.

Two later review choices remain: obtain an exact matching `2.43-8` build-only
closure if available, or isolate static compilation in a separately pinned
build stage with its resolved NEVRA set recorded. Either needs reviewed
build-only/toolchain provenance; neither authorizes upgrading the final
543-package base or the shared dynamic-binary build stage. This task chooses
neither and does not emit a purported production static binary.

## Reproducible commands

All remote probes used:

```sh
ssh -o ControlMaster=no -o ControlPath=none -o BatchMode=yes \
  -o ConnectTimeout=10 coreos@<development-host> '<command>'
```

The fixed cached image above was assigned to `BASE` solely to shorten commands:

```sh
podman image exists "$BASE"
podman image inspect --format '{{.Id}} {{.Digest}}' "$BASE"
podman run --rm --pull=never --network=none --read-only \
  --entrypoint /bin/sh "$BASE" -c '
    rpm -q --qf "%{NAME}-%{EPOCHNUM}:%{VERSION}-%{RELEASE}.%{ARCH}\n" \
      glibc glibc-common glibc-devel glibc-static gcc binutils make rust cargo
    for p in /var/cache/dnf /var/cache/libdnf5 /usr/bin/gcc /usr/bin/cc \
      /usr/bin/ld /usr/lib64/libc.a /usr/lib64/libc.so.6; do
      if test -e "$p"; then ls -ld "$p"; fi
    done'
podman run --rm --pull=never --network=none --read-only \
  --entrypoint /bin/sh "$BASE" -c '
    dnf --cacheonly --setopt=logdir=/tmp --disable-plugin="*" repoquery \
      --available --qf "%{name}-%{epoch}:%{version}-%{release}.%{arch}" \
      glibc-static glibc-devel gcc binutils
    printf "repoquery_exit=%s\n" "$?"'
podman run --rm --pull=never --network=none --read-only \
  --entrypoint /bin/sh "$BASE" -c '
    LC_ALL=C rpm -qa \
      --qf "%{NAME}-%{EPOCHNUM}:%{VERSION}-%{RELEASE}.%{ARCH}\n" \
      | LC_ALL=C sort | sha256sum'
```

The first cache-only attempt used default `/var/log` and failed with a read-only
filesystem error before metadata lookup; it is **not** evidence of package
availability. The recorded retry redirected only disposable-container logs to
`/tmp`, then reached the explicit no-cache result above.
