## Distribution and trust boundary

The qcow2 intentionally retains the development origin
`localhost/signallayer-coreos:0.0.3`. Registry provisioning remains an operator
responsibility. The release does not publish a production update channel.

Artifacts are not cryptographically signed. The annotated Git tag, OCI
identities and SHA-256 records provide traceability and content-integrity
checks; the checksums alone do not authenticate the publisher.

The complete known limitations and deferred hardening boundary are recorded in
the [0.0.3 release notes](0.0.3.md) and the frozen
[remote-management contract](../remote-management-0.0.3.md).
